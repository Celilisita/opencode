- 使用会话的 web 搜索提供商搜索网络 - 执行实时网络搜索，并可从特定 URL 抓取内容
- 为当前事件和最新数据提供时效信息
- 支持可配置的结果数量，返回最相关网站的内容
- 需要访问知识截止日期之后的信息时使用该工具
- 搜索在单次 API 调用内自动完成

用法说明：
  - 可用时支持实时抓取模式：'fallback'（缓存不可用时备用）或 'preferred'（优先实时抓取）
  - 可用时的搜索类型：'auto'（均衡）、'fast'（快速结果）、'deep'（全面搜索）
  - 可配置上下文长度以优化 LLM 集成
  - 提供域名过滤和高级搜索选项

当前年份是 {{year}}。搜索最新信息或当前事件时，必须使用该年份
- 示例：若当前年份是 2026，用户要"最新 AI 新闻"，就搜"AI 新闻 2026"，而不是"AI 新闻 2025"
